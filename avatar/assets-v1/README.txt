ANEMO VTUBER — LIVE2D ASSET PACK V1
=========================================

This V1 is a DESIGN/ASSET REFERENCE PACK generated from the approved character direction.
It is NOT yet a production-ready, fully separated PSD and does not contain a finished .moc3 model.

MAIN CHARACTER DIRECTION
- Front-facing bust-up
- Anime / semi-realistic gaming creator aesthetic
- Black + gold fantasy jacket
- Cyan/teal Anemo-inspired wind effects
- Character remains the primary focal point

RECOMMENDED LIVE2D LAYERS
01_HEAD
  Face, Ear_L, Ear_R, Hair_Back, Hair_Side_L, Hair_Side_R, Hair_Front
02_EYES
  EyeWhite_L/R, Iris_L/R, Pupil_L/R, Highlights, Eyelashes
03_BROWS
  Brow_L/R
04_MOUTH
  Mouth_Base, Mouth_Inside, Teeth, Tongue, Mouth_Shapes
05_BODY
  Neck, Shirt, Jacket, Accessories
06_EFFECTS
  Anemo_Wind, Particles, Glow
07_BACKGROUND (optional)
  Background / Atmosphere

CORE PARAMETERS
- ParamAngleX: -30 / 0 / +30
- ParamAngleY: -20 / 0 / +20
- ParamAngleZ: -30 / 0 / +30
- EyeOpen_L/R: 0..1
- EyeBallX/Y: -1..+1
- Brow_L/R: -1..+1
- MouthOpen: 0..1
- MouthForm/Smile: -1..+1
- BodyAngleX/Y: subtle movement
- Hair physics: secondary motion
- Cloth/accessory physics: subtle

EXPRESSIONS
Normal, Senyum, Tertawa, Kaget, Marah, Sedih, Malu

IMPORTANT
For a true Live2D production file, hidden/occluded areas must be redrawn behind
the moving layers (especially hair/face/neck/jacket). V1 therefore serves as the
visual and structural starting point before final PSD cleanup and rigging.
